# Dereference Operator in C

**Author:** M.Likitha

## Description

This program demonstrates the dereference operator `*` in C.

The dereference operator is used to access the value stored at the memory address held by a pointer. It can also be used to modify that value.

## Concepts Used

- Pointers
- Dereference operator `*`
- Memory addresses
- Modifying values through pointers

## Sample Output

```text
Original value: 85
Value using dereference operator: 85
Value after modifying through pointer: 120
